# The Bevy Co. website

Static site for The Bevy Co., a cocktail bar and lounge at 22 Poverty Rd, Southbury, CT.

- `index.html` is the one-page site: story, fall menu, private events, gift cards, hours and contact.
- `style-guide.html` is the brand reference: logo, colors, type and buttons.
- `assets/` holds the logo files and photos.

There is no build step. Open `index.html` in a browser, or serve the folder with any static host.

## Notes

- Reservations and gift cards link to the existing Toast pages.
- The logo SVGs were traced from a PNG and should be replaced with the original vector artwork.
- Fonts (Hepta Slab, Barlow, Mrs Saint Delafield) load from Google Fonts.
